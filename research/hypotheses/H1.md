# H1 — Video advantage

**상태(status): untested**

## 가설 (계약서 §42 원문)

> Passive low-motion 환경에서도 multi-frame temporal modeling은 frame-only PAD보다 일부 spoof attack에 추가 단서를 제공한다.

## 관련 연구 질문

- RQ1 (§4): Video가 frame-only PAD보다 실제로 도움이 되는가? — 작은 landmark movement, local facial motion, display flicker, moiré 변화, reflection 변화, temporal compression artifact, frame timing, rPPG 유사 cue.

## 관련 실험 (§43 1차 실험 매트릭스)

| ID | Backbone | Input | DA | Target Data | 목적 |
|---|---|---|---|---|---|
| E01 | Frame baseline | 1 frame | None | None | Source-only baseline |
| E02 | Video baseline | 8 frames | None | None | Temporal gain |

E02 − E01의 차이(전체 및 **공격 유형별** APCER, §14.2)가 이 가설의 1차 증거다. Low-motion protocol(§28)에서도 재확인해야 한다.

## 채택/기각 기준

- 같은 `protocol_hash` 아래에서 E02가 E01 대비 최소 한 공격 유형의 APCER를 seed variance(§31) 이상으로 개선하면 지지.
- 개선이 전체 ACER에만 나타나고 공격 유형별로 사라지면 결론을 유보한다(§30).

## 증거

- 아직 없음. **합성(synthetic) 데이터로 돌린 run은 sanity check일 뿐이며 이 가설의 증거가 아니다** (synthetic runs are NOT evidence; ADR-005).
- 실데이터(H100 서버) 결과가 나오면 `experiments/reports/`의 리포트와 MLflow run ID를 여기에 링크하고 상태를 갱신한다.
